## 中文

在白板上写词块、画图，并用带标签的连线整理想法。可以将整张白板备份为 JSON，或只导出所选内容供 AI 阅读。

- Windows x64 解压 ZIP 后双击 `MindFlow.exe`。Linux x64 解压 tar.gz 后运行 `./mindflow-desktop`。两个包均自带运行时，未经代码签名。
- 在桌面版的「MCP 接入」中复制本地客户端配置。默认只读，取消勾选后可允许客户端编辑白板。
- [网页版](https://moyx782.github.io/mindconnect/)在浏览器中保存数据。使用完整 JSON 备份在网页和桌面之间迁移白板。
- Linux 桌面交互和 MCP 读写已实测。Windows 通过了构建和自动测试，图形界面未做人工验收。

## English

Write cards, sketch, and connect ideas with labeled lines. Back up the whole board as JSON or export a selection for an AI client to read.

- On Windows x64, extract the ZIP and run `MindFlow.exe`. On Linux x64, extract the tar.gz and run `./mindflow-desktop`. Both packages include the runtime and are unsigned.
- Open **MCP 接入** (MCP setup) in the desktop app to copy the local client configuration. Access is read-only by default. Clear the checkbox to allow edits.
- The [web edition](https://moyx782.github.io/mindconnect/) saves in the browser. Use a full JSON backup to move a board between web and desktop.
- Desktop interactions and MCP reads and writes were verified on Linux. Windows passed the build and automated tests. Its GUI was not manually tested.

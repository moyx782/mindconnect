## 中文

网页和桌面版现在可以在中文与英文 之间切换。工具栏、快捷键、导出和 MCP 设置使用所选语言。切换语言会保留词块和连线的原文。内置示例、使用说明和 MCP 工具说明均提供中英双语。

Windows x64 解压 ZIP 后运行 `MindFlow.exe`。Linux x64 解压 tar.gz 后运行 `./mindflow-desktop`。若移动了桌面程序，请在「MCP 接入」中重新复制配置并重新加载客户端连接。

## English

Switch between Chinese and English in the web and desktop apps. The toolbar, shortcuts, export controls and MCP setup follow your language choice. Card text and connection labels stay as written. The sample board, documentation and MCP tool descriptions are available in both languages.

On Windows x64, extract the ZIP and run `MindFlow.exe`. On Linux x64, extract the tar.gz and run `./mindflow-desktop`. If you move the desktop app, copy its configuration from **MCP setup** again and reload the client connection.
